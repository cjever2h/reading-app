# 독서앱 · AI각인 독서기록

독서 시간, 수집한 문장, 독서노트, AI 독서 대화를 한 곳에 쌓아 서평·SNS 콘텐츠·독서모임 발제로 바로 잇는 반응형 웹앱(PWA).
설계: 「독서앱 설계서」(2026-10-14, 네오) · 가이드 흐름: 『AI가 각인시켜주는 독서법』

## 기능
| 단계 | 기능 |
| --- | --- |
| 1 | 서재(읽고 싶은 책·읽는 중·완독, 표지 그리드, 장르·태그), 알라딘 검색(제목·저자·키워드·ISBN), 독서 타이머(화면이 꺼져도 시간 유지), 독서 인증 이미지(정사각형·세로형, 페이지 사진 자르기·가리기), 문장 수집(쪽수·공감/의문/연결 메모·태그), 독서노트(읽기 전·일일·챕터별·자유 템플릿), 문장·노트 통합 검색 |
| 2 | AI각인 독서가이드(읽기 전·읽는 중·날마다 읽기 대화·읽은 후·활용), 빠른 참조 카드 12종, 72시간 복습(D+1·D+3·D+7 '오늘의 복습'), 30일 실험, 통계(일·주·월 시간, 쪽수, 연속 독서일, 월별 완독) |
| 3 | 서평 초안·카드뉴스 카피·스레드·발제 질문 내보내기, 마크다운·노션 전송, 사진 문장 인식(OCR) |

## 구조
- 빌드 없는 정적 사이트(Vercel). 데이터는 Supabase(Postgres + RLS + Storage), 로그인 계정별로 분리.
- `api` Edge Function(`edge-function-api.ts`): 알라딘 OpenAPI 프록시, AI 대화, 표지 이미지 프록시, 노션 전송, OCR.
- 비밀값(Supabase → Edge Functions → Secrets)
  - `ALADIN_TTB_KEY`: 알라딘 TTB 키. 없으면 Google Books로 임시 검색.
  - `GEMINI_API_KEY` 또는 `OPENAI_API_KEY` 또는 `ANTHROPIC_API_KEY`: AI 가이드·OCR. 없으면 질문·힌트 중심 가이드와 브라우저 OCR로 동작.
  - (선택) `NOTION_TOKEN`: 설정 화면에 토큰을 넣지 않을 때 쓰는 기본 노션 토큰.
- `schema.sql`: 테이블(books, reading_sessions, quotes, notes, summaries, action_experiments, review_tasks, guide_sessions, settings), 태그 뷰(tag_index), RLS, 사진 버킷.

## 가이드 원칙
사용자가 먼저 쓴다(입력 전에는 AI 피드백 없음) · 질문은 한 번에 하나 · 현재 읽은 쪽 이후 내용은 말하지 않음 · 별점은 직접 입력 · 타 책 교차 분석은 기본 꺼짐(설정에서 켜기) · 장르 5종별 프롬프트 자동 선택(설정에서 원고 부록 문구로 편집 가능).

도서 정보 제공: 알라딘 (TTB 키 등록 시)
